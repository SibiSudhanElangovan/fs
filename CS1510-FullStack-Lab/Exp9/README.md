# Experiment 9 — Project Management Dashboard

Start MongoDB locally. In terminal 1: `cd Exp9/backend`, `npm install`, `npm start` (API on port 5000). In terminal 2: `cd Exp9/frontend`, `npm install`, `npm start` (React on port 3000). The UI can add tasks and update their status among Pending, In Progress, and Completed. MongoDB database: `project_dashboard`.
