# Experiment 4 — AngularJS To-do Manager

Run from this directory with a local static server (for example, `npx http-server -p 8080`) and open `http://localhost:8080`. Opening via `file://` may block AngularJS template requests in some browsers.

Sample login: `Raghavi` / `pass@123` (also `user2` / `pass2`). Users and tasks are mock in-memory data and reset when the page is reloaded.
